# Localização Kitanda
Português de Angola é a língua de reserva. As traduções nacionais são experimentais, não revistas por falantes especializados. A percentagem na escolha de língua mede apenas as chaves centralizadas, não a totalidade da interface. Não confundir palavras traduzidas com uma interface completa.

## Antes de declarar uma língua completa
Extrair os textos restantes de login, vendas, produtos, dívidas, clientes, equipa, comprovativos e erros de RPC. Rever cada frase no contexto com falantes da variedade angolana, em especial termos financeiros e permissões. Validar pluralização, textos dinâmicos, nomes, moeda e datas. Manter português quando faltar tradução. Não enviar dados pessoais de comerciantes a serviços externos de tradução.

## Kimbundu — expansão preliminar
Mais termos aplicados em formulários, autenticação, vendas, relatórios e definições. Frases compostas são propostas para revisão, não traduções certificadas. Referências: https://www.kimbundu.org/pt/word/dijina ; https://www.kimbundu.org/en/word/kitadi ; https://www.kimbundu.org/pt/word/kusota ; https://www.kimbundu.org/fr/word/kubaka ; https://www.kimbundu.org/pt/word/dimi ; https://www.kimbundu.org/pt/learn/commands ; https://www.kimbundu.org/pt/word/ila . Não apresentar os textos restantes em português como tradução completa. Rever especialmente as frases financeiras, o fluxo de autenticação e os convites com um falante.
